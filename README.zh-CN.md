# 时之笛 (Switch2/3DS)：陶笛按键对照表

[English](README.md) | 中文

《塞尔达传说 时之笛》（Nintendo Switch2）陶笛按键对照表，覆盖 C5 到 E6 的音。

## 基本规则

游戏中的陶笛有五个基础音：

| 按键 | 音名 |
| ---- | ---- |
| L    | D5   |
| R    | F5   |
| A    | A5   |
| Y    | B5   |
| X    | D6   |

演奏时可以改变音高：

- **⇧** = 摇杆往**上**推到底：升高一个全音
- **⇩** = 摇杆往**下**推到底：降低一个全音
- **↑/↓** = **十字键上 / 下**：升高 / 降低半音

## C 大调简谱对照表（1=C5）

适用于音域在 1 到高音 3 之间的简谱。第一种是全摇杆按法，第二种是十字键备选。

| 简谱 | 实际音 | 按法        | 另一种按法  |
| ---- | ------ | ----------- | ----------- |
| 1    | C5     | L⇩          | —           |
| 2    | D5     | L           | —           |
| 3    | E5     | L⇧          | R＋十字键下 |
| 4    | F5     | R           | —           |
| 5    | G5     | A⇩          | R⇧          |
| 6    | A5     | A           | —           |
| ♯6   | A♯5    | Y＋十字键下 | A＋十字键上 |
| 7    | B5     | Y           | —           |
| 高 1 | C6     | X⇩          | Y＋十字键上 |
| 高 2 | D6     | X           | —           |
| 高 3 | E6     | X⇧          | —           |

## 全音域对照表（C5–E6）

时之笛能准确吹出的全部 17 个音。转写新曲子时可以逐音查表。同一行的升号和降号是同一个音。

| 音名      | 摇杆按法 | 十字键按法                 |
| --------- | -------- | -------------------------- |
| C5        | L⇩       | —                          |
| C♯5 / D♭5 | —        | L＋十字键下                |
| D5        | L        | L                          |
| D♯5 / E♭5 | —        | L＋十字键上                |
| E5        | L⇧       | R＋十字键下                |
| F5        | R        | R                          |
| F♯5 / G♭5 | —        | R＋十字键上                |
| G5        | A⇩ 或 R⇧ | —                          |
| G♯5 / A♭5 | —        | A＋十字键下                |
| A5        | A        | A                          |
| A♯5 / B♭5 | —        | Y＋十字键下 或 A＋十字键上 |
| B5        | Y        | Y                          |
| C6        | X⇩       | Y＋十字键上                |
| C♯6 / D♭6 | —        | X＋十字键下                |
| D6        | X        | X                          |
| D♯6 / E♭6 | —        | X＋十字键上                |
| E6        | X⇧       | —                          |

## 曲谱示例

### 欢乐颂（G 大调）

全曲用 6 个音，**C6**可以是**Y↑**也可以是**X⇩**，在演奏时可以按个人习惯选择。

| 简谱 | 低 5 | 1   | 2   | 3   | 4     | 5   |
| ---- | ---- | --- | --- | --- | ----- | --- |
| 音名 | D5   | G5  | A5  | B5  | C6    | D6  |
| 按键 | L    | A⇩  | A   | Y   | Y↑/X⇩ | X   |

**第一句**

```
简谱：3  3  4  5  │ 5  4  3  2  │ 1  1  2  3  │ 3  –  2  2
音名：B5 B5 C6 D6 │ D6 C6 B5 A5 │ G5 G5 A5 B5 │ B5 – A5 A5
按键：Y  Y  Y↑ X  │ X  Y↑ Y  A  │ A⇩ A⇩ A  Y  │ Y  – A  A
```

**第二句**

```
简谱：3  3  4  5  │ 5  4  3  2  │ 1  1  2  3  │ 2  –  1  1
音名：B5 B5 C6 D6 │ D6 C6 B5 A5 │ G5 G5 A5 B5 │ A5 – G5 G5
按键：Y  Y  Y↑ X  │ X  Y↑ Y  A  │ A⇩ A⇩ A  Y  │ A  – A⇩ A⇩
```

**第三句**

```
简谱：2  2  3  1  │ 2  3-4   3  1  │ 2  3-4   3  2  │ 1  2  5̣
音名：A5 A5 B5 G5 │ A5 B5-C6 B5 G5 │ A5 B5-C6 B5 A5 │ G5 A5 D5
按键：A  A  Y  A⇩ │ A  Y-Y↑  Y  A⇩ │ A  Y-Y↑  Y  A  │ A⇩ A  L
```

**第四句**（同第二句）

```
简谱：3  3  4  5  │ 5  4  3  2  │ 1  1  2  3  │ 2  –  1  1
音名：B5 B5 C6 D6 │ D6 C6 B5 A5 │ G5 G5 A5 B5 │ A5 – G5 G5
按键：Y  Y  Y↑ X  │ X  Y↑ Y  A  │ A⇩ A⇩ A  Y  │ A  – A⇩ A⇩
```
