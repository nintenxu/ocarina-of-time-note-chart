# Ocarina of Time (Switch2/3DS): Ocarina Note Chart

English | [中文](README.zh-CN.md)

A button chart for playing any melody on the ocarina in *The Legend of Zelda: Ocarina of Time* (Nintendo Switch2), with every note from C5 to E6.

## How it works

The ocarina has five base notes:

| Button | Note |
| ------ | ---- |
| L      | D5   |
| R      | F5   |
| A      | A5   |
| Y      | B5   |
| X      | D6   |

You can change the pitch while playing:

- **⇧** = hold the Circle Pad fully **up**: raises the note by a whole step
- **⇩** = hold the Circle Pad fully **down**: lowers the note by a whole step
- **D-pad up / down**: raises / lowers the note by a half step

## C major chart

The notes most C major songs need, from C5 to E6 plus B♭. The first method uses only the Circle Pad; the alternative uses the D-pad or a different base button.

| Note      | Buttons        | Alternative    |
| --------- | -------------- | -------------- |
| C5        | L⇩             | —              |
| D5        | L              | —              |
| E5        | L⇧             | R + D-pad down |
| F5        | R              | —              |
| G5        | A⇩             | R⇧             |
| A5        | A              | —              |
| B♭5 / A♯5 | Y + D-pad down | A + D-pad up   |
| B5        | Y              | —              |
| C6        | X⇩             | Y + D-pad up   |
| D6        | X              | —              |
| E6        | X⇧             | —              |

## Full-range chart (C5–E6)

All 17 notes the ocarina can play in tune. To transcribe a song, pick a key that keeps the melody inside this range, then look up each note. Sharps and flats on the same row are the same pitch.

| Note      | Circle Pad method | D-pad method                   |
| --------- | ----------------- | ------------------------------ |
| C5        | L⇩                | —                              |
| C♯5 / D♭5 | —                 | L + D-pad down                 |
| D5        | L                 | L                              |
| D♯5 / E♭5 | —                 | L + D-pad up                   |
| E5        | L⇧                | R + D-pad down                 |
| F5        | R                 | R                              |
| F♯5 / G♭5 | —                 | R + D-pad up                   |
| G5        | A⇩ or R⇧          | —                              |
| G♯5 / A♭5 | —                 | A + D-pad down                 |
| A5        | A                 | A                              |
| A♯5 / B♭5 | —                 | Y + D-pad down or A + D-pad up |
| B5        | Y                 | Y                              |
| C6        | X⇩                | Y + D-pad up                   |
| C♯6 / D♭6 | —                 | X + D-pad down                 |
| D6        | X                 | X                              |
| D♯6 / E♭6 | —                 | X + D-pad up                   |
| E6        | X⇧                | —                              |

## Song Example

### Ode to Joy (G major)

Beethoven's theme uses six notes. **C6** can be either **Y↑** or **X⇩**, choose the one that feels comfortable to you.

| Note    | D5  | G5  | A5  | B5  | C6    | D6  |
| ------- | --- | --- | --- | --- | ----- | --- |
| Buttons | L   | A⇩  | A   | Y   | Y↑/X⇩ | X   |

**Phrase 1**

```
Notes:   B5 B5 C6 D6 │ D6 C6 B5 A5 │ G5 G5 A5 B5 │ B5 – A5 A5
Buttons: Y  Y  Y↑ X  │ X  Y↑ Y  A  │ A⇩ A⇩ A  Y  │ Y  – A  A
```

**Phrase 2**

```
Notes:   B5 B5 C6 D6 │ D6 C6 B5 A5 │ G5 G5 A5 B5 │ A5 – G5 G5
Buttons: Y  Y  Y↑ X  │ X  Y↑ Y  A  │ A⇩ A⇩ A  Y  │ A  – A⇩ A⇩
```

**Phrase 3**

```
Notes:   A5 A5 B5 G5 │ A5 B5-C6 B5 G5 │ A5 B5-C6 B5 A5 │ G5 A5 D5
Buttons: A  A  Y  A⇩ │ A  Y-Y↑  Y  A⇩ │ A  Y-Y↑  Y  A  │ A⇩ A  L
```

**Phrase 4** (same as phrase 2)

```
Notes:   B5 B5 C6 D6 │ D6 C6 B5 A5 │ G5 G5 A5 B5 │ A5 – G5 G5
Buttons: Y  Y  Y↑ X  │ X  Y↑ Y  A  │ A⇩ A⇩ A  Y  │ A  – A⇩ A⇩
```
